# Stocking Lab / A-Stock Quant Lab V4.0 人工测试路径

本文档用于人工完整走查当前 V4.0 版本。测试者不需要懂代码，只需要按页面点击、输入、运行、截图，并把异常截图反馈给 GPT / Codex。

当前 `app.py` 的实际左侧导航顺序是：

1. 数据质量
2. 数据中心
3. 策略实验室
4. 回测中心
5. 参数优化器
6. 策略排行榜
7. 组合回测
8. 策略稳定性
9. 研究工作流
10. 候选复检
11. 实验中心
12. 今日选股
13. 个股分析

说明：用户验收清单中把“数据中心”放在第一位，但当前程序实际把“数据质量”放在第一位。人工测试时以左侧实际页面名称为准。

## 1. 测试前准备

### 环境命令

在 Windows 终端执行：

```bat
cd /d "C:\Users\18961\Documents\Stock Trading"

git checkout main
git pull origin main
git status

python --version
pip install -r requirements.txt
python -m pytest -q
python -m ruff check .
python -m compileall .
python scripts\validate_project.py
streamlit run app.py
```

预期结果：

- `git status` 应显示在 `main`，且除 `storage/stock_quant.db` 这类本地数据文件外没有业务代码变更。
- `python --version` 应显示 Python 3.11 或更高。
- `pytest` 应通过。
- `ruff` 应显示 `All checks passed!`。
- `validate_project.py` 应显示 `PASSED: all checks completed`。
- Streamlit 启动后浏览器访问 `http://localhost:8501`。

如果 `storage/stock_quant.db` 已有本地数据，请先复制备份：

```bat
copy storage\stock_quant.db storage\stock_quant_backup_manual_qa.db
```

不要提交数据库文件。人工测试可能写入实验、报告记录、股票池 snapshot、审计记录，这是正常的本地运行数据变化。

### 启动方式

小白启动方式：

1. 双击 `scripts/windows/start_streamlit_no_proxy.bat`。
2. 脚本会自动进入项目目录、临时清除当前窗口里的代理变量、设置 `NO_PROXY=*`、测试东方财富网络，然后启动 Streamlit。
3. 如果窗口提示“网络已能访问东方财富，可以继续启动 Streamlit。”，继续在浏览器打开 `http://localhost:8501`。
4. 如果窗口提示“你的系统或代理软件仍在强制代理”，请关闭 VPN/代理软件，或去 Windows 设置里关闭代理，再重新双击脚本。

只检查东方财富网络、不启动 Streamlit：

1. 双击 `scripts/windows/check_eastmoney_network.bat`。
2. 查看窗口中的 `HTTP_STATUS` 或中文错误提示。

如果仍然出现 ProxyError：

1. 关闭 Clash / v2rayN / VPN / 加速器。
2. 打开 Windows 设置 → 网络和 Internet → 代理。
3. 关闭“使用代理服务器”。
4. 重新双击 `scripts/windows/start_streamlit_no_proxy.bat`。

命令行启动方式：

```bat
streamlit run app.py
```

浏览器地址：

```text
http://localhost:8501
```

首次测试建议使用小范围数据，不要一开始就全市场多年审计或 deep 研究。

## 3. 测试数据规模建议

### Smoke Test

- 1 到 3 只股票。
- 1 年数据。
- 用于快速确认页面不崩、按钮可点、空状态友好。

建议：

- 股票：`000001`、`600519`、`300750`
- 区间：最近 1 年
- 参数优化和稳定性分析使用默认或最小参数。

### Small Research Test

- 5 到 20 只股票。
- `2020-01-01` 至今。
- 用于策略、回测、组合回测、稳定性、研究工作流、候选复检。

建议：

- 股票：`000001`、`000002`、`600519`、`600036`、`300750`
- 批量更新数量：5 到 20
- 研究模板：`quick`
- 组合最大持仓：3 到 5

### Full Research Test

- 全市场。
- 多年数据。
- 仅在 Smoke 和 Small Research 稳定后再运行。

注意：

- 全市场多年审计、参数优化、walk-forward、deep 研究可能耗时较久。
- 如果页面长时间运行，先用小范围复现，不要直接判断系统不可用。

## 4. 页面级测试路径

## 数据质量

### 测试目标

验证 V4.0 数据健康、审计、问题明细、股票池构建、复权口径和数据质量报告导出。

### 操作步骤

1. 打开左侧“数据质量”。
2. 在“数据健康概览”查看股票数、行情记录、最新交易日、CRITICAL/WARNING、`adjust_type` 分布。
3. 切换到“运行数据审计”。
4. `scope` 选择 `daily_prices`，日期选择 `2020-01-01` 到今天，`adjust_type` 选择 `qfq`，最大检查股票数设为 5 或 10。
5. 保持“检查交易日缺口”“检查幸存者偏差”“检查复权一致性”勾选，点击“运行审计”。
6. 切换到“问题明细”，按 severity、issue_type、code 或 keyword 筛选。
7. 切换到“股票池构建”，设置 `as_of_date` 为最近交易日，`universe_name` 填 `manual_qa_small`，保留默认筛选，点击“构建股票池”。
8. 查看 `stock_count`、warnings、codes 表。
9. 点击“保存 snapshot”，确认显示 snapshot id、stock_count 和 warnings count。
10. 切换到“数据质量报告”，选择刚才的 run，点击“导出 Markdown 报告”和“导出 issues CSV”。

### 建议输入

- `scope`: `daily_prices`
- `adjust_type`: `qfq`
- `max_codes`: 5 或 10
- `universe_name`: `manual_qa_small`
- `min_list_days`: 250
- `use_current_stock_list_fallback`: 勾选

### 预期结果

- 审计完成后出现 run id 和 summary。
- 如果旧行情没有真实 `adjust_type` 字段，应显示 `unknown` / legacy / assumed adjust type warning。
- 股票池构建后出现 codes 表。
- 使用 current stock list fallback 时，应出现幸存者偏差 warning。
- 保存 snapshot 后，显示的 `stock_count` 应与页面展示一致。
- 报告导出显示文件路径和大小。

### 正常空状态

- 初次无数据时，数据健康概览的行情记录可能为 0。
- 没有 issue 时，问题明细可以为空，但应有友好提示。
- 没有 data_quality_run 时，报告页会提示先运行审计。

### 异常情况

- 页面红色 traceback。
- 旧行情缺少 `adjust_type` 却静默显示为 `qfq`。
- 审计没有任何 warning，也没有解释 legacy/unknown。
- 股票池 snapshot 保存后的 stock_count 与页面展示不一致。
- warnings_json 没有记录 survivorship bias warning。

### 建议截图

- 数据健康概览。
- 审计完成 summary，尤其 legacy adjust_type warning。
- 问题明细筛选结果。
- 股票池构建结果和保存 snapshot 成功提示。
- 数据质量报告导出成功提示。

## 回测中心

### 测试目标

验证单策略回测、次日开盘买入、止盈止损、gross/net 成本对比、实验保存和市场环境分析。

### 操作步骤

1. 打开“回测中心”。
2. 选择“MA20回踩策略”或“趋势强势股策略”。
3. 设置开始日期 `2020-01-01`，结束日期为最新日期。
4. 持仓周期选择 20。
5. 勾选“跌破MA20卖出”。
6. 止盈选择 10%，止损选择 8%。
7. 先不启用真实交易成本，点击“运行回测”。
8. 再勾选“启用真实交易成本”，保持默认费用，重新运行。
9. 输入实验名称和标签，点击“保存本次单策略回测”。

### 建议输入

- 策略：`MA20回踩策略`
- 持仓周期：20
- 止盈：10%
- 止损：8%
- 实验标签：`manual_qa,single_strategy`

### 预期结果

- 显示 total_trades、win_rate、avg_return、CAGR、sharpe_ratio、max_drawdown 等指标。
- 显示 Equity Curve 和 Drawdown Curve。
- 启用成本后应显示 gross/net 或成本影响提示。
- 交易明细中买入日应晚于信号日。
- 保存实验后显示 experiment_id。

### 正常空状态

- 若策略在小样本中没有信号，回测 trades 为空是正常的，但页面应说明无交易。

### 异常情况

- 回测使用信号日当天开盘买入。
- 启用成本后 net return 反而长期大于 gross return 且无解释。
- 最大回撤出现明显不合理值且权益曲线不匹配。

### 建议截图

- 回测指标卡。
- Equity Curve / Drawdown Curve。
- 交易明细第一几行，包含 signal_date/buy_date。
- 保存实验成功提示。

## 策略稳定性

### 测试目标

验证 V3.2 样本内/样本外、Walk-forward、参数敏感性、过拟合风险、市场环境分组和实验保存。

### 操作步骤

1. 打开“策略稳定性”。
2. 选择“MA20回踩策略”。
3. 日期区间选择 `2020-01-01` 到最新日期。
4. train_ratio 保持 0.7。
5. Walk-forward 训练月数先用 12 或 18，测试月数 3 或 6，步长 3 或 6。
6. 使用默认参数网格；若运行较慢，可只保留一两个参数值。
7. 点击“运行稳定性分析”。
8. 查看稳定性评分、过拟合风险、样本内/样本外 net_CAGR、Walk-forward 正收益比例、参数稳定性评分、推荐结论。
9. 查看 Walk-forward folds、参数搜索 Top、市场环境、过拟合 flags。
10. 点击“保存为稳定性实验”。

### 建议输入

- 策略：`MA20回踩策略`
- train_ratio：0.7
- 训练月数：12 或 24
- 测试月数：6
- 步长月数：6

### 预期结果

- 显示稳定性评分和过拟合风险。
- Walk-forward fold 表有 train/test 区间，test 晚于 train。
- 参数敏感性表不应包含无效参数维度。
- 市场环境来源应显示 HS300 或 fallback。
- 保存实验后可在实验中心查看。

### 正常空状态

- 数据少或交易少时，可能显示样本不足、needs more data、HIGH/MEDIUM overfit risk，这是正常研究结论。

### 异常情况

- 使用测试集数据调参的迹象。
- 参数网格字段被显示但实际策略不使用。
- 市场环境全为空且没有 fallback/样本不足提示。

### 建议截图

- 稳定性指标卡。
- Walk-forward fold 表。
- 参数敏感性结果。
- 过拟合 flags。
- 保存实验成功提示。
